Séquence 1 · Lesson 1 · Number bingo

À ne pas projeter : les élèves doivent entendre le nombre. Le script Python de la séquence s'exécute ici, dans le navigateur. Après un nombre piège (13…19 ou 30…90), son « jumeau » sort souvent juste après.

Python n'est pas encore chargé.

Raccourcis : espace ou Entrée pour tirer, R pour réécouter.

L'élève lit ses trois nombres alignés ; tapez-les pour vérifier qu'ils ont bien tous été tirés (sinon, il a sans doute confondu fifteen et fifty…).
