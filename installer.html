Installer l'appli Maths Lebrun sur ton téléphone

2 minutes, gratuit, sans passer par un store.

← Retour au site

Une fois installée, l'appli s'ouvre d'un seul geste depuis ton écran d'accueil, en plein écran, comme une vraie application : cours, exercices interactifs et automatismes.

Adresse du site https://clemenceletousey.github.io/Maths/

Avec Chrome, le navigateur installé d'office sur la plupart des téléphones Android.

  1. Ouvre le site dans Chrome

    Tape l'adresse ci-dessus ou scanne le QR code donné en classe.

  2. Ouvre le menu

    Appuie sur les trois points Menu en haut à droite de l'écran.

  3. Choisis « Ajouter à l'écran d'accueil »

    Selon ton téléphone, la ligne peut s'appeler « Installer l'application ». C'est la même chose.

  4. Confirme avec « Installer »

    Si Chrome te le propose, appuie ensuite sur « Ajouter » ou fais glisser l'icône sur l'écran de ton choix.

Tu as un Samsung avec Samsung Internet ? Appuie sur le menu Menu en bas à droite, puis « Ajouter la page à » → « Écran d'accueil ».

Avec Firefox : menu ⋮ → « Ajouter à l'écran d'accueil ».

Avec Safari, le navigateur à la boussole bleue, installé sur tous les iPhone.

  1. Ouvre le site dans Safari

    Tape l'adresse ci-dessus ou scanne le QR code donné en classe avec l'appareil photo.

  2. Appuie sur le bouton Partager

    C'est le carré avec une flèche vers le haut Partager, en bas de l'écran. Si tu ne le vois pas, appuie d'abord sur les trois points ···.

  3. Choisis « Sur l'écran d'accueil »

    Fais défiler la liste vers le bas pour trouver la ligne avec un petit + dans un carré. Elle s'appelle aussi parfois « Ajouter à l'écran d'accueil ».

  4. Appuie sur « Ajouter »

    En haut à droite. Laisse le nom « Maths Lebrun ». Si l'option « Ouvrir en tant qu'app web » apparaît, laisse-la activée.

Tu utilises Chrome sur iPhone ? Appuie sur l'icône Partager Partager dans la barre d'adresse, puis « Sur l'écran d'accueil ». Si l'option n'y est pas, repasse par Safari.

C'est installé ! Cherche cette icône sur ton écran d'accueil. Elle s'ouvre directement sur le site, sans barre d'adresse.

Ça ne marche pas ?

Je ne trouve pas la bonne ligne dans le menu
  • Fais défiler le menu jusqu'en bas : la ligne est souvent cachée plus loin.
  • Vérifie que tu es bien dans le navigateur (Chrome ou Safari), et pas dans l'aperçu ouvert par Instagram, Snapchat, Pronote ou l'ENT. Dans ce cas, choisis d'abord « Ouvrir dans le navigateur ».
Sur iPhone, je ne vois pas « Sur l'écran d'accueil »
  • Tout en bas de la liste Partager, appuie sur « Modifier les actions » et active « Sur l'écran d'accueil ».
  • Navigation privée : quitte-la et recommence dans un onglet normal.
Je veux supprimer l'appli
  • Appui long sur l'icône, puis « Supprimer » (ou « Désinstaller » sur Android). Rien d'autre n'est effacé de ton téléphone.
